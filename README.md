# Python Optimized Auto Clicker
Dont trust those eerie websites with shady apk, download links?
Fear not, when you have the power of programming. (In this case python)

## ✨Features
* Clicks at high speeds on demand
* Runs in the background; optimized for minimal CPU usage
* Simple activation and deactivation protocols

## ❔ Usage
* Press `a` to start the autoclicker
* Press `b` to stop the autoclicker
* To change the speed, simply open the `py` file, navigate to the `delay` variable, and change the value to your heart's content.
